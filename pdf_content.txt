Project Title
AI-Powered Sports Engagement Content Agent
Objective
Develop an AI agent capable of generating engaging, multi-format sports content for
Instagram quizzes, polls and more. The system should leverage web search to ensure factual
accuracy and fresh content, and should support multiple engagement formats beyond
simple MCQs.
Problem Statement
Traditional sports content on social media is largely limited to news, highlights, and
opinion-based posts. Even interactive formats are often limited to a single question type
(MCQ), which becomes repetitive for followers over time.
The goal of this project is to build an agent that generates multiple types of interactive
content quizzes, true/false challenges, opinion polls, and fill-in-the-blank prompts so
content creators can vary their engagement strategy, keep followers interested, and match
the right format to the right platform surface (Story, Feed, Reel caption).
All content generated is text-based no image generation or image sourcing is required.
Output should be ready to drop into Instagram's native text/sticker tools (Quiz sticker, Poll
sticker, caption text, etc.).

ΓùÅ Choose a difficulty level (Easy, Medium, Hard)
ΓùÅ Choose a question/content type:
Γùï Multiple Choice Question (MCQ)
Γùï True / False
Γùï This-or-That Poll (no single correct answer ΓÇö pure opinion/engagement)
Γùï Fill in the Blank (with 4 answer options)

AI Agent Requirements
ΓùÅ Use web search to gather recent or fast-changing sports information (recent match
results, records, transfers, tournament outcomes)
ΓùÅ Combine retrieved context with the LLM to generate high-quality content for each
format
ΓùÅ Avoid hallucinations by grounding all factual claims in retrieved information; the
agent should be able to cite which source (web search or vector DB) supported each
answer
ΓùÅ Generate fresh and diverse content on every request ΓÇö avoid repeating the same
question/fact across sessions
ΓùÅ Apply a type-specific generation template for each content type (an MCQ prompt
template, a True/False template, a Poll template, etc.) rather than one generic
prompt for everything
ΓùÅ Validate every generated item against a schema for its type before returning it (e.g.,
MCQ must have exactly 4 options and 1 correct answer; Poll must have exactly 2
options and no correct answer; Guess-the-Number must have a numeric target plus
an acceptable range)
